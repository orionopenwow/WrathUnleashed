Play

Add your game client first. Leyline uses the client already on your PC; it never downloads game files.

Clients

Point Leyline at a game folder you already have: 3.3.5a (build 12340) or 1.12.1 (build 5875). It reads the build from the executable and the data files, and checks the install looks complete.
